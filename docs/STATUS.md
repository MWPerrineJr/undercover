# Status

Pilot phases 1–4 are complete. The persisted claims API and backend-only LangChain agent now have a handler dashboard: full queue and evidence, policy and customer/history, read-only instructions, live operational activity, decisions/calculations/citations, handler sign-off and separate simulated payment. Active claims poll until work finishes. An approved payment that fails after sign-off can be retried without repeating sign-off.

Run `uv sync` and `npm install` at the root, then `npm run dev`. Backend: http://localhost:8000; API reference: http://localhost:8000/docs; dashboard: http://localhost:5173. Database: `undercover.sqlite3` (ignored), overridden by `UNDERCOVER_DB`. Set `OPENROUTER_API_KEY` in `.env`; default model is `openai/gpt-6-luna` with low reasoning effort; `MODEL_NAME` overrides it. `BACKEND_URL` defaults to http://localhost:8000 (also overrides Vite's backend proxy).

Start a waiting claim with Run agent. Above $1,000, select a handler and Sign off and pay. Payments are simulated and must exactly match the stored approval. Failed/interrupted runs without decisions return to waiting for an explicit retry; saved decisions/payments survive and unpaid approvals offer Record payment. The app has no sign-in or durable agent checkpointing.

Verification: Python checks pass 27 tests at 99.71% coverage; TypeScript checks pass 9 tests with 100% statement coverage. Browser review against an isolated real API/scripted model completed a normal approval, over-limit sign-off/payment, live activity and instructions, with desktop and mobile/dark screenshots, no page errors and no horizontal overflow. Playwright MCP was unavailable, so the installed Playwright browser was used. No test called OpenRouter or opened evaluation records. Full end-to-end automation is next.
